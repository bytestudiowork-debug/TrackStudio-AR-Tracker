# Third-party build and licensing notes

This repository includes third-party components. Their source code, copyright notices and license terms are maintained with the corresponding dependency sources.

Before redistributing a build:
- Review the license files shipped with each included component.
- Preserve all required copyright and license notices.
- Check the licenses of transitive dependencies, not only the top-level component.
- Do not assume that one component's license applies to the entire application.

Internal build architecture, dependency pins and engineering status are intentionally not documented here.
